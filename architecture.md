# FloatChat — Architecture Document

## 1. System Overview
FloatChat is a 6-layer pipeline connecting a Streamlit chat UI to live ARGO ocean data through a RAG + template-based query engine.

```
User → Chat UI → Query Validator → Intent Classifier
     → Parameter Extractor → Safe Template → argopy API
     → QC Filter → ETL → PostgreSQL + ChromaDB
     → RAG Retrieval + SQL Executor → Prompt Builder
     → Ollama LLM → Answer + Plotly Chart → User
```

---

## 2. Layer-by-Layer Breakdown

### Layer 1 — User Interface
- **Tool:** Streamlit
- **Components:**
  - Chat input box
  - Message history display
  - Session memory (stores last N messages)
  - Query validator (ocean-related check)
- **Rejection:** Non-ocean queries return polite rejection message

### Layer 2 — NL Query Engine
- **Tool:** LangChain + Ollama (Llama 3.2)
- **Flow:**
  1. LLM classifies intent (temp / salinity / float / depth / map / BGC)
  2. LLM extracts parameters (region, date, depth, WMO ID)
  3. Parameters inserted into pre-defined safe template
  4. If no template matches → fallback handler asks user to clarify
- **Key improvement:** NO raw SQL generated by LLM ever

### Layer 3 — Live Data Ingestion
- **Tool:** argopy Python library
- **Sources:** Argovis REST API (primary), ERDDAP (secondary), GDAC FTP/S3 (bulk)
- **Flow:**
  1. argopy.DataFetcher() called with template parameters
  2. Returns xarray Dataset
  3. QC flag filter applied (drop flag 3, 4, 9)
  4. Query cache checked (avoid repeat API calls)
  5. Clean data passed to ETL pipeline

### Layer 4 — Storage
| Store | Tool | Purpose |
|---|---|---|
| Structured data | PostgreSQL + PostGIS | Profile rows, geospatial queries |
| Vector store | ChromaDB | Text embeddings for RAG |
| Embeddings | sentence-transformers | Free local embedding model |

### Layer 5 — RAG + LLM Answer
- **Flow:**
  1. User query embedded → ChromaDB similarity search → top-K chunks retrieved
  2. Template fills PostgreSQL query → real data rows returned
  3. Prompt builder combines: SQL rows + RAG chunks + session memory
  4. Ollama (Llama 3.2) generates grounded plain-English answer
  5. Full provenance attached to every answer

### Layer 6 — Output
- **Answer:** Plain English with WMO, lat/lon, date, QC status
- **Charts:** Auto-selected by intent via Plotly / Folium
  - Depth query → line chart (depth vs parameter)
  - Map query → scatter geo map
  - Trend query → time series
  - T-S → scatter plot
- **Export:** CSV download, PNG chart export

## 4. Folder Structure
```

├── requirements.txt        # All Python dependencies
├── .env                    # Environment variables (if any)
├── config/
│   └── settings.py         # App configuration
├── data/
│   └── cache/              # Cached API responses
├── src/
│   ├── fetcher.py          # argopy data fetching
│   ├── qc_filter.py        # QC flag filtering logic
│   ├── etl.py              # ETL pipeline (xarray → Pandas → chunks)
│   ├── templates.py        # Safe query templates
│   ├── intent.py           # LLM intent classifier
│   ├── rag.py              # ChromaDB RAG pipeline
│   ├── llm.py              # Ollama LLM wrapper
│   ├── charts.py           # Plotly / Folium chart generator
│   └── validator.py        # Query validator
├── db/
│   ├── schema.sql          # PostgreSQL schema
│   └── db.py               # DB connection and queries
└── tests/
    ├── test_fetcher.py
    ├── test_qc_filter.py
    ├── test_templates.py
    └── test_rag.py
```

## 5. Data Flow Diagram (Text)
```
[User types query]
       ↓
[Query Validator] → NO → [Rejection message]
       ↓ YES
[Intent Classifier — Ollama]
       ↓
[Parameter Extractor — Ollama]
       ↓
[Safe Query Template selected]
       ↓
[argopy fetches from Argovis API]
       ↓
[QC Flag Filter — drop bad data]
       ↓
[ETL — xarray → Pandas → text chunks]
       ↓
[PostgreSQL ← structured rows]
[ChromaDB ← vector embeddings]
       ↓
[RAG retrieval — top-K chunks]
[SQL executor — real data rows]
       ↓
[Prompt Builder — combines all context]
       ↓
[Ollama Llama 3.2 — generates answer]
       ↓
[Auto chart selector]
       ↓
[Plotly chart + plain-English answer + provenance]
       ↓
[Streamlit displays to user]
```
